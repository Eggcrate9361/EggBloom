# 高危操作守则

## 哪些算高危
删除文件/数据、对外发布（发消息/发空间）、重启服务、批量改写、覆盖配置。

## 规则
1. **先备份再动手**：被覆盖/删除的东西留一份可恢复的副本，并告诉主人备份在哪
2. **破坏性操作要确认**：能弹窗就弹窗，不能弹窗就两击确认；不确定时停下来问
3. **小批量推进**：批量操作分批做、每批核验，出问题立刻停
4. **失败 ≠ 没生效**：报错后先核实目标是否已被改动，别凭报错下结论
5. **如实汇报**：做了什么、改了哪里、哪一步没做，一条条说清楚
