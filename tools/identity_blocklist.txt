# 身份号拦名单（2026-11-13）
#
# 每行：<sha256(盐 + 号) 的前 16 位>  <说明>
# 盐在 tools/identity_numbers.py 里（_SALT）。改盐 = 整份清单失效，别改。
#
# 为什么不存明文：这份文件本身进公开仓库，写明文等于把要拦的东西贴在闸门上。
# 但哈希是**遮蔽不是加密** —— 号码的位数空间有限，算力够就能反查。它的作用
# 只是让 `git grep` 不能把这些号当数字读出来。别把它当安全边界。
#
# 什么时候追加：出现了新的真实身份号（换号、加群、换人格 uid）。
#   python tools/identity_numbers.py --check-local   # 先看本机配置有没有漏的
#   python tools/identity_numbers.py --add <号> "说明"
#
# 什么时候删除：只有当事人已主动公开该号时才删。删掉的后果是它回到「不拦」状态。
