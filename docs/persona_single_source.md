## 顺手修的真 bug：身份块从来没生效

`_id_block` 里引用了 `_nick_line`，而这个名字**在 bot_core 里从未定义**；
整块又包在 `try/except Exception: pass` 里 → `NameError` 被静默吞掉，
`【你是谁（事实…）】` 一直没进过 prompt（真机验过）。

现在补上 `_nick_line = "、".join(f"「{n}」" for n in _nicks[:3] if n)`，
身份块恢复注入（网名 / 群名片 / QQ 号 / 别名指代），且**只有事实、没有指令**。
