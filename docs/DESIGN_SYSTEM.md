# EggBloom 设计规范 v1.5

> 适用对象：`webui/webui_artistic_v3.html`（全站单文件 SPA，14 页）
> 配套可视化规范表：`_ref/design/spec.html`（渲染图 `_ref/design/spec-part01~03.png`）
> 制定：2026-10-03

---

## 0. 为什么要有这份规范

现状实测：

| 指标 | 现状 |
|---|---|
| 内联 `style="…"` | **430 处** |
| `class="card"` / `class="panel"` | 19 / 18 处 |
| `panel-title` | 24 处 |
| 设计令牌 | 只有颜色与阴影，**没有间距刻度、字号刻度** |

"AI 味"不是颜色的错，是这三条叠加的结果：
1. **430 处硬编码像素** —— 每个元素的大小位置都手写，整体永远差一点；
2. **`panel` 盒子是默认容器** —— 一屏多个等大带边框盒子，是模板化仪表盘的长相；
3. **层级靠边框建立** —— 而不是字号/字重/留白，于是每块看起来一样重要。

**本规范的目标：把 430 处内联样式压到接近 0，把盒子换成线与字。**

---

## 1. 四条原则

| 原则 | 含义 |
|---|---|
| **无盒** no box | 不用边框、圆角、阴影划分区域。只用 1px 发丝线与留白。 |
| **字级** type scale | 层级只由字号 / 字重 / 字距 / 留白产生。最大最小字号对比 **13:1**。 |
| **裸露** bare data | 数字直接落在背景上，等宽 + `tabular-nums`。不装卡片、不配装饰。 |
| **活性** living ui | 强调色随 EGO 情绪偏移；只有真正"活着"的东西才允许脉动。 |

## 2. 令牌（唯一真源，直接粘贴到 `:root`）

```css
:root{
  /* 底色：永远中性，不用彩色底 */
  --bg:#08080a; --bg2:#0c0c0f; --bg3:#101014;

  /* 线条：只有三种亮度 */
  --line:#191920;  /* 区块内分隔（最常用） */
  --line2:#232329; /* 区块之间 / 输入框底线 */
  --line3:#32323a; /* 悬停加深 */

  /* 文字：四级足够 */
  --ink:#f2f0f5; --ink2:#a6a4ae; --ink3:#6a6874; --ink4:#403e48;

  /* 强调色：由 EGO 情绪注入，默认「平静」 */
  --accent:#c9a96e;
  --accent-dim:#8a7350;
  --accent-glow:rgba(201,169,110,.16);

  /* 语义色：只用于状态，不用于装饰 */
  --ok:#6f9e78; --warn:#d0a45c; --err:#b05a52;

  --f-s:'Outfit','Noto Sans SC','PingFang SC',system-ui,sans-serif;
  --f-m:'JetBrains Mono','Consolas',monospace;

  /* 字号阶梯：z1→z9，对比 13:1 */
  --z1:9px;  --z2:10px; --z3:11.5px; --z4:13px; --z5:16px;
  --z6:21px; --z7:30px; --z8:52px;  --z9:120px;

  /* 间距：只用 8 的倍数 */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px;
  --s5:24px; --s6:32px; --s7:48px; --s8:72px;

  /* 运动：只有三种时长 */
  --t-fast:120ms;   /* 悬停/聚焦/按下 */
  --t-page:320ms;   /* 换页 */
  --ease:cubic-bezier(.4,0,.2,1);
}
```

**铁律**：组件里**禁止出现字面量颜色、像素字号、像素间距**。一律 `var()`。

## 3. 字号阶梯

| 令牌 | 值 | 用途 | 字重 / 字距 |
|---|---|---|---|
| `--z9` | 120px | 巨型数字，一屏最多一个 | 200 / `-.04em` |
| `--z8` | 52px | 页面标题、关键指标 | 200–300 / `-.035em` |
| `--z7` | 30px | 次级指标 | 300 / `-.02em` |
| `--z6` | 21px | 区块标题 | 300 / `-.02em` |
| `--z5` | 16px | 强调正文 | 500 / 0 |
| `--z4` | 13px | **正文与表单值（占全站 80%）** | 400 / 0 |
| `--z3` | 11.5px | 等宽数据、路径、ID | 400 / 0 |
| `--z2` | 10px | 次级数据 | 400 / `.04em` |
| `--z1` | 9px | **标签**：大写 + `letter-spacing .18em` + `--ink4` | 400 |

中文标签**不转大写，只拉字距** —— 这是中文界面里最有效的一招。

## 4. 七大原语（全站只允许这些容器）

> **卡片不在其中。** 任何"想用卡片"的场合，从下表里挑一个。

| # | 原语 | 规则 | 替代掉 |
|---|---|---|---|
| ① | **`stat`** 裸露指标 | 标签(`--z1`) + 数值(`--z7/z8/z9`) + 一行上下文(`--z2` `--ink4`)。无边框无底色 | `StatCard` / `.card` + `.card-value` |
| ② | **`kv`** 定义列表 | `<dl>` 两列网格，`dt` 用 `--z2 --ink4`，`dd` 用 `--z3/--z4`。行间距 `--s1` | `KeyValueCard` |
| ③ | **`cmd`** 命令行按钮 | 等宽 + 大写 + 方角 + 1px `--line2` 描边。主操作：`--accent` 字色 + `--accent-dim` 描边 + `--accent-glow` 底。动作带 `<kbd>` 提示 | `.btn` / `.btn.primary` / `.btn.ghost` |
| ④ | **`fld`** 底线输入框 | `background:transparent; border:0; border-bottom:1px solid var(--line2)`，聚焦时底线变 `--accent`。标签在输入框**上方**用 `--z1` | `.input` 方形输入框 |
| ⑤ | **`row`** 表行 | `grid` 多列 + `border-bottom:1px solid var(--line)`。表头行用 `--z1` 大写 | `.card` 网格（群/好友列表） |
| ⑥ | **`sig`** 点 + 字状态 | 5px 圆点 + `--z2` 文字 + `letter-spacing .13em`。**无胶囊、无底色**。活的状态才加 `box-shadow` 光晕 | `.pill` / `.dot` 胶囊 |
| ⑦ | **`log`** 编辑器式日志 | 四列 grid：行号(44px，右对齐 + 右边线) / 时间(74px) / 级别(92px，染色) / 正文。整块 `--bg2` 底，**无边框** | 普通 `<div>` 日志列表 |

### 区块头（把盒子换成线）

```html
<div class="sec-h">
  <span class="lab">状态</span>      <!-- --z1 大写 -->
  <i class="rule"></i>                <!-- flex:1; height:1px; background:var(--line) -->
  <span class="meta">12:04:33 刷新</span>
</div>
```

**这是本规范最核心的一个动作**：原来用 `panel` 盒子表达的"分组"，现在用「小标签 + 一条通到底的线 + 右侧说明」表达。

## 5. 数据即图形（纯 CSS/SVG，不引图表库）

### 铁律：图形必须承载数据，否则删掉它

> 明确的产品判断：**不要华而不实的东西。完全没有用处的图表一律不做。**

- **允许**：图形 = 真实数据的另一种读法（24h 消息量、发言时段分布、预算水位）。
- **禁止**：为了"好看/填充版面"而存在的装饰图形、没有数据来源的示意图、纯氛围动画。
- **判定方法**：把图形删掉，信息是否丢失？**不丢失 → 删掉它。**

> 现有 `webui/chart.min.js` 205 KB **全项目零引用**，不应再引入任何图表库。

| 图形 | 用途 | 画法 | 承载的数据 |
|---|---|---|---|
| **迷你柱** spark | 时序变化 | flex + 每根一个 `<i>`，高度百分比；非峰值降透明度 | 每小时消息量（24 点） |
| **递减条** meter | "水位"类指标 | 6 条 2px 横线，宽度与透明度递减 | Token 预算余量 |
| ~~点阵 matrix~~ | ~~时段分布~~ | 已降级：24 格信息密度不如迷你柱，且易沦为装饰 | — |
| ~~落沙 sand~~ | ~~记忆沉积~~ | **仅在映射真实记忆条数时可用**，否则删除 | 记忆条数 |

四种图形都**只用 `var(--accent)` 一个颜色**，靠透明度分层。

## 6. 运动（本规范的一等公民）

> 产品判断：**动态效果才是"高级感"最直观的体现**，但它必须由真实事件驱动。
> **总原则：只有"真的发生了事情"才动；静止就是静止。**

| # | 效果 | 触发条件 | 表现 | 参数 |
|---|---|---|---|---|
| 1 | **情绪色迁移** | EGO 情绪变化 | 全站 `--accent` 插值过渡，不是瞬间跳变 | 600ms · `--ease` |
| 2 | **数值滚动** | 真实数值变化 | 等宽数字从旧值滚到新值 | 200ms · `--ease` |
| 3 | **基线脉冲** | 数值上升/下降 | 数字下方 1px 基线闪一下；上升偏 `--accent`，下降偏冷 | 400ms |
| 4 | **日志落位** | 真的产生新行 | 新行从下方 6px 淡入落位 | 240ms |
| 5 | **连接呼吸** | 连接活着 | 2.4s 呼吸；**断开时呼吸停止、点变红并静止** | 2.4s infinite |
| 6 | **操作过程可见** | 用户触发动作 | 按钮→进行态 → 状态点 灰→黄→绿 → 日志依次落位 | 全流程可见 |
| 7 | **打字指示** | bot 正在生成回复 | 对应位置三个呼吸点 | 1.2s stagger |
| 8 | **页面落位** | 换页 | 内容从 4px 下方淡入落位（不做滑动/翻转） | 320ms |
| 9 | **落沙重置** | 一次蒸馏完成 | 记忆点阵从顶部重新落（一次性） | 800ms |

**第 5 条是本规范的灵魂**：静止本身携带信息 —— 该呼吸的东西不呼吸了，就是出事了。

**禁止**：弹跳缓动、旋转、缩放整块内容、超过 400ms 的过渡（第 1/5 条除外）、给静态元素加动画。

**定格演示**：`_ref/design/motion-demo.html` + `motion_shots.py`（用负 `animation-delay` 冻结在精确时刻，可复现）。

## 7. 情绪驱动强调色（本规范最"极致"的一条）

EGO 情绪状态机已经在跑。把它的状态写进一个 CSS 变量，**全站换肤不需要重绘、不加类、不动任何组件**：

```js
// 放在情绪更新处，一次调用
const MOOD_ACCENT = {
  calm:      { a:'#c9a96e', d:'#8a7350', g:'rgba(201,169,110,.16)' }, // 平静（默认）
  lively:    { a:'#d9a24e', d:'#96702f', g:'rgba(217,162,78,.16)'  }, // 活跃
  irritated: { a:'#c07a56', d:'#7d4c33', g:'rgba(192,122,86,.16)'  }, // 烦躁
  low:       { a:'#8f9bb0', d:'#5b6474', g:'rgba(143,155,176,.14)' }, // 低落
};
function applyMoodAccent(mood){
  const m = MOOD_ACCENT[mood] || MOOD_ACCENT.calm;
  const r = document.documentElement.style;
  r.setProperty('--accent', m.a);
  r.setProperty('--accent-dim', m.d);
  r.setProperty('--accent-glow', m.g);
}
```

效果：**界面颜色 = 机器人当前情绪**。烦躁时全站偏红、低落时退冷 —— 这不是装饰，是状态可视化。

## 8. 落地铁律（改 400 KB 单文件时必须遵守）

1. **JS 逻辑一行不改。** 只改 `<style>` 块与模板里的 class / 容器层级。
2. **选择器是红线。** 迁移前先扫出 JS 里所有 `getElementById` / `querySelector` / `data-*` 依赖的 id 与 class，**这些必须原样保留**。改 class 名之前先确认没有 JS 在用。
3. **逐页迁移。** 顺序按"最重→最轻"：协议页 → 群管理 → 表情包 → 生图 → 群聊行为 → Token → 配置中心 → Bot → 日志控制 → 仪表盘 → 通知 → 记忆 → 底层控制 → 插件管理。
4. **每页一次 git 提交。** 出问题只回滚一页。
5. **每页迁完跑一次交互清单**（该页所有按钮/开关/表单都要点一遍）。

## 9. 禁止清单

| ✕ 禁止 | ✓ 采用 |
|---|---|
| 带边框/圆角/阴影的等大盒子 | 发丝线 + 留白分组 |
| 胶囊状状态标签（带底色） | `sig`：点 + 字 |
| 方形输入框 | `fld`：底线输入框 |
| 圆角色块按钮 | `cmd`：等宽大写方角 |
| 内联 `style="font-size:12px"` | `--z*` 令牌 |
| 5px / 7px / 13px / 15px 间距 | `--s*`（8 的倍数） |
| 引入图表库 | CSS/SVG 手绘四种图形 |
| 给静态元素加动画 | 只给实时状态加脉动 |
| 彩色装饰背景 | 底色永远中性 |
