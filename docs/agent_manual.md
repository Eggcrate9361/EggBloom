## work（13）

只读工作型 —— 读 / 找 / 搜，零副作用，可常驻

### `ws_read`

读取工作区内的文本文件，返回带行号的内容。行号可直接用于 edit。长文件用 offset/limit 翻页。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | string | 是 | 文件路径（相对路径即相对项目根） |
| `offset` | integer | 否 | 起始行号，1 起，默认 1 |
| `limit` | integer | 否 | 读取行数，默认 200 |

来源：`harness`

### `ws_glob`

按文件名模式查找文件（如 '*.py'、'**/*.json'）。结果按最近修改时间倒序。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pattern` | string | 是 | 文件名模式，支持 * 和 ? |
| `path` | string | 否 | 搜索起始目录，默认项目根 |
| `limit` | integer | 否 | 最多返回条数，默认 50 |

来源：`harness`

### `ws_grep`

用正则搜索工作区文件内容，返回 文件:行号: 内容。定位代码/日志时首选。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pattern` | string | 是 | 正则表达式 |
| `path` | string | 否 | 搜索的文件或目录，默认项目根 |
| `glob` | string | 否 | 只搜匹配该模式的文件，如 '*.py' |
| `ignore_case` | boolean | 否 | 忽略大小写 |
| `context` | integer | 否 | 上下文字行数，0-3 |
| `limit` | integer | 否 | 最多返回条数，默认 50 |

来源：`harness`

## write（3）

### `ws_edit`

精确替换文件中的一段原文（含缩进必须完全一致）。要求 old_string 在文件中唯一，否则拒绝执行并给出候选位置 —— 这是为了不改错地方。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | string | 是 | 文件路径 |
| `old_string` | string | 是 | 要替换的原文（须与文件内容完全一致） |
| `new_string` | string | 否 | 替换后的文本；留空表示删除该段 |
| `replace_all` | boolean | 否 | 为 true 时替换全部匹配（默认 false，要求唯一） |

### `ws_write`

创建新文件，或整体重写已存在的文件（会清空原内容，需显式 overwrite=true）。只改一部分请用 ws_edit。

## proc（6）

执行型 —— 起进程 / 跑代码，成本最高

### `py_run`

在**持久 Python 会话**中执行代码（变量/import/cwd 跨调用保留）。做数据处理、计算、批量文件操作、调库时用它。最后一行可以是表达式，会打印其值。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | string | 是 | 要执行的 Python 代码 |
| `timeout` | number | 否 | 超时秒数，默认 20，上限 120 |
| `session` | string | 否 | 会话名，默认 default（不同名即不同环境） |
| `reset` | boolean | 否 | 为 true 时先重启会话（清空全部变量） |

来源：`harness`

### `job_start`

在后台启动任务（不阻塞；适合长任务）：给 path 跑 Python 脚本，或给 cmd 直接跑命令。长任务用 job_wait 一次等到结束，别用 job_output 反复轮询。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | string | 否 | 脚本文件路径（与 cmd 二选一） |
| `cmd` | ['string', 'array'] | 否 | 内联命令：字符串走 shell，或直接给 argv 列表（如 ["python","-u","-c","..."]） |
| `args` | array | 否 | 传给脚本的命令行参数 |
| `label` | string | 否 | 任务显示名 |

来源：`harness`

### `job_output`

读取后台任务的**新增**输出（增量，不重复）。wait=true 时等它结束（有上限）。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `job_id` | string | 是 | job_start 返回的任务号 |
| `wait` | boolean | 否 | 等待任务结束或超时 |
| `timeout_ms` | number | 否 | 等待上限（毫秒），仅 wait=true 时有效 |

来源：`harness`

### `job_wait`

**一次调用阻塞等到后台任务结束**（内部每 2 秒看一眼）。20 分钟的下载只消耗 1 次工具调用，不要用 job_output 反复轮询。until 可传正则（等某行出现就返回），默认 exit=等进程退出。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `job_id` | string | 是 | 任务号 |
| `max_sec` | number | 否 | 最多等多久（秒），默认 120，上限 120 |
| `until` | string | 否 | 'exit'（默认）或正则，命中即返回 |

来源：`harness`

### `job_list`

_无参数_

来源：`harness`

## deep（1）

多步任务 —— 只在「可干活」打开时注入

### `deep_task`

**要通读多个文件 / 审查代码 / 连着多步动手时，第一轮就用它** —— 不要先一个个 ws_glob 列目录（工具轮次会被烧光，然后只能回「还没读完」）。它把整件活干完，回给你一段结果文字，你照常回话（别把过程念给用户听）；要读的范围写进 task。闲聊、一句话能答的别用 —— 它比直接回答慢得多。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `task` | string | 是 | 要它干什么，一句话说清（含必要的对象/路径） |
| `context` | string | 否 | 可选：已知的上下文（用户原话、已知信息） |

来源：`harness`
