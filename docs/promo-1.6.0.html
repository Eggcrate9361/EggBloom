RELEASE NOTE — 1.6.0
1.6.0

一个大脑，一个出口。

1.5.x 一直在解决「像不像人」：人格只剩一个文件、记忆按人隔离、说过的话要认。 1.6.0 换的是骨架——agent 不再是模式而是工具，所有消息走同一条生成链；出口收成一个队列； 生图、语音、转写共用一套任务层，而且都在本地跑。

01

这一版换的是骨架

THREE LINES
P0通路

一个大脑

删掉「agent 模式」。群里 @ 它干活，和 @ 它闲聊，走同一条生成链：人格、记忆、预算、闸、审计、出口，一套。开关从「换人格」变成「多一双手」。

harness/life_context.py · deep_task · agent_can_work · reply_budget
P1出口

一个出口

文本、图片、表情、戳一戳，全部进一个队列：串行、限频、去重、重试、留日志。插件再多也绕不过去，漏发与抢话第一次变得可以定位。

harness/outbound.py · Channel · plugin manifest · 4 个生命周期钩子
P1.5扩展位

一组 AIGC 扩展位

「生图 / ComfyUI」扩成「AIGC / 扩展位」：图、语音、视频、素材四个页签，共用一套任务模型与产物目录。后端留给使用者自己接，默认全关，不是本版能力。

harness/aigc_task.py · piper · faster-whisper · data/media

05

已经打好的地基

1.5.11 · FROZEN

1.6.0 不动这三层：人格、记忆、诚实。它们已在 1.5.11 收口，本版只改接线，不改内容。

D1—D2

人格只剩一个文件

提示词、规则、人格曾经三处各写一份，互相打脸。现在只有 personality.txt，分【我是谁】【怎么说话】【不许】三层；出口再加一道 reply_guard，号码、露后台、念简历由代码兜底。

0 COST
D3—D5

记忆按人、按场景

QQ 是主键，别名 > 群名片 > 昵称 > 裸号；同群重名能列出两个 uid。跨场景双向：群里说过的事私聊接得上，但只注入说话人自己的内容，别人的一字不进。

+约 1K TOKEN / 轮
D6—D7

说过的话要认

事实抽取带 src 与置信度，低置信度不进 prompt、只进待确认队列。认账闸在发送前拦「我没说过」——自述账本 + 否认检测，私聊群聊同一判据。

≈¥0.001 / 轮
记忆保险启动快照，按天留 14 份；恢复前先给当前文件留档。
人格蒸馏L0–L4 分级，多源取证 → 人工审核 → 保存；一次 L2 约 31.4 万 token。
阈值可配慢回填充、存图回看、表情上下限、认账三项，全部即时生效。
热补丁4 MB 级增量，只覆盖代码与页面；人格、自建插件、数据、配置一律不动。
