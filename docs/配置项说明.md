# 配置项说明

本文由 `scripts/export_config_docs.py` 从 `scripts/_fieldmeta.json`、
`config.DEFAULT_CONFIG` 与 `bot_config.json.example` 自动生成，**不要手工编辑**。

配置页（控制台 → 配置中心）能改的每一项都在这里，含含义、默认值与改了要不要重启。
键名以 `bot_config.json.example` 为准；页面上的中文标签来自 v3 的字段标记，
与本文是同一份数据的两面。

表里「默认值」一列：

- `—` = `config.DEFAULT_CONFIG` 里没有这个键。它仍可能生效 —— 代码用
  `_config.get("key", 兜底值)` 直接读，兜底值写在读取处（本地模型路径、
  ComfyUI 参数这类）。要看兜底值，搜 `bot_core.py` 里的键名。
- 「重启」列标「要」的项，改完必须重启后端进程才生效；其余热生效。

## 一致性是怎么保证的

- 配置页的字段标签、控件形态、说明：v3 的字段标记 → `extract_field_meta.py`
- 默认值与「要不要重启」：`config.DEFAULT_CONFIG` 与 `bot_core` 的模块级常量 → `patch_field_defaults.py`
- 本文与上面的审计：`export_config_docs.py`

改任何一个配置键，按这个顺序跑：

```
python scripts/extract_field_meta.py      # v3 标记 → _fieldmeta.json
python scripts/patch_field_defaults.py    # 补 default / restart
python scripts/inject_field_meta.py       # 注入 v4 页面
python scripts/export_config_docs.py      # 导出本文 + 三处一致性审计
```
