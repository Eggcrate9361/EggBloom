# EggBloom 1.6.0 — 一个大脑，一个出口

> 整包发布 · 版本真相源 `package.json` · 2026-11-09

1.5.x 解决的是「像不像人」：人格单源、记忆按人、说过的话要认。
1.6.0 换的是**骨架**：所有消息走同一条生成链，所有产物走同一个出口。
它不是事件路由加插件生态，是一个人的完整运行时。

## 这版改了什么

- **一条生成链**：`harness/life_context.compose()` 是唯一上下文入口，人格、记忆、插件注入、场感、时间锚不再四处拼装；agent 从「另一种模式」变成模型可调用的一个工具。
- **一个出口**：文本、图片、表情包、戳一戳统一进单队列（串行 / 限频 / 去重 / 重试 / 落盘回执）。超时这类「不确定失败」先校验送达再决定重发，不再让用户收到两条一样的回复。
- **长任务不再随重启消失**：统一任务中心 + workflow DAG + cron 调度，任务落盘、跨进程续等、失败可恢复。
- **会自己开口**：14 条触发、规则与模型混合仲裁、共享预算与静默时段；视频理解走远端取帧与逐张视觉判读。
- **控制台 v4**：15 页，配置中心、插件状态页与当前能力对齐。

## 边界（这版不是什么）

- **只支持 Windows**；要一台常开机器，API Key 自备。
- **AIGC 只是扩展位**：图 / 声 / 字留了任务层、四个 API 和接线位，后端要自己装自己接，默认全关。本版不承诺「能画、能说、能听」。
- **分离与真实**是启动期判定的不可逆内核态：默认关、只在终端启用、本地无回滚。源码库与常规发行包都不落 `SEPARATION.lock`。
- **自主开发层只预演**：`devloop` 默认不执行，不自带改码 / 重启 / 回归执行器；插件自验只做静态检查，仍需管理员审批。
- 插件市场、手机 / 内容平台 / MC 通道的真实驱动、自愈 R3 自动改代码，均**不在本版**。
- QQ 通道走 OneBot v11，属非官方接入，可能违反《腾讯 QQ 用户服务协议》；建议小号、低频重启。
