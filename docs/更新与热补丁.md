# 更新与热补丁（2026-11-01）

## 现状：没有自动更新器

发行版是便携目录：`EggBloom Desktop.exe` + `resources\app`（Python 侧）。
在此之前用户拿新版本只能整包重下（200MB+）再覆盖。

程序内"更新"能力分三层：

| 层 | 机制 | 覆盖范围 |
|---|---|---|
| 配置热重载 | 保存 → `POST /reload_config` → `reload_config()` | 只有 `bot_config.json` 里的配置 |
| 代码/页面 | 换文件 + webui_server 重启（Electron 守护，3s 拉起） | `.py` / `.html` / 评测用例 |
| Electron 壳 | 只能换安装包 | 全部（含 exe） |

## 热补丁（给终端用户）

### 发布侧

```powershell
# 1) 打补丁（默认从上一个 tag 起的改动；--all 是全量白名单）
python scripts/make_patch.py --version 1.5.11 --url https://<发布地址>/patch-1.5.11.zip --notes "修了什么"

# 产物：
#   dist/patch-1.5.11.zip   只含白名单路径，几 MB
#   dist/latest.json        {version, sha256, size, url, files}
```

把两个文件挂到 GitHub Releases（或任何静态服务器），`latest.json` 的地址写进
用户端的 `update_manifest_url`。

### 用户侧

```powershell
# 查
python -m harness.updater --check
# 装（先下 zip，再带 manifest 应用；应用后重启程序）
python -m harness.updater --apply patch-1.5.11.zip --manifest latest.json
# 回滚
python -m harness.updater --rollback data\update-backup\<时间戳>
```

### 安全边界（写死在代码里）

- 只覆盖白名单：`harness/ plugins/ webui/ evals/ skills/ protocols/` + 根目录 `.py`
- 拒：`data/ logs/ memes/ image_cache/ ...`、`bot_config.json`、`.env`、`tests/`
- 拒：`../`、绝对路径、盘符
- sha256 不匹配 → 不写盘
- 覆盖前逐文件备份到 `data/update-backup/<时间戳>/`
