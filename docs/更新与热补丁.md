# 更新与热补丁（2026-11-01）

## 现状：没有自动更新器

发行版是便携目录：`EggBloom Desktop.exe` + `resources\app`（Python 侧）。
在此之前用户拿新版本只能整包重下（200MB+）再覆盖。

程序内"更新"能力分三层：

| 层 | 机制 | 覆盖范围 |
|---|---|---|
| 配置热重载 | 保存 → `POST /reload_config` → `reload_config()` | 只有 `bot_config.json` 里的配置 |
| 代码/页面 | 换文件 + webui_server 重启（Electron 守护，3s 拉起） | `.py` / `.html` / 评测用例 |
| Electron 壳 | 只能换安装包 | 全部（含 exe） |

## 热补丁（给终端用户）

### 发布侧

```powershell
# 1) 打补丁（默认从上一个 tag 起的改动；--all 是全量白名单）
python scripts/make_patch.py --version 1.6.1 --url https://<发布地址>/patch-1.6.1.zip --notes "修了什么"

# 产物：
#   dist/patch-1.6.1.zip   只含白名单路径，几百 KB ~ 几 MB
#   dist/latest.json        {version, sha256, size, url, files, base}
```

把两个文件挂到 GitHub Releases（或任何静态服务器），`latest.json` 的地址写进
用户端的 `update_manifest_url`；**资产名必须叫 `latest.json`**，
配置项默认值是 `/releases/latest/download/latest.json`，靠的就是这个固定文件名。

> **私有仓库拉不到**：仓库还是 private 时，`releases/latest/download/*` 对匿名请求返回
> **404**（2026-11-15 实测）。要么仓库转公开，要么把 `update_manifest_url`
> 指到自己的镜像 / 对象存储。

### 版本记账（2026-11-15）

`VERSION` 在 `DENY_NAMES` 里 —— 补丁只写 `resources\app`，改不到它。
所以打完补丁会另记一份：

```
data/update-state.json    {version, applied_at, files, backup_dir}
```

`updater._read_version()` 取 `VERSION` 与这份记账里**更大的那个**，
`is_newer()` 才不会每次都为真（否则控制台永远挂着同一个「发现新版本」）。
`rollback()` 成功时删掉这份记账，版本退回 `VERSION` 里那个值。

> 已知边界：重装整包但保留 `data/` 时，记账会一起留下 —— 那时程序实际是 1.6.0，
> 却自称 1.6.1，不会再提示这个补丁。要重新收到提示，删掉 `data/update-state.json`。

### 行尾（2026-11-15）

发行包里的文本是 **CRLF**，而 `base` 哈希来自 `git show` 读出的 blob（**LF**）。
两边不对齐时，用户本地每个官方文件都会被判成「被自己改过」→ 全进 `kept` →
补丁一个文件也落不了地。现在两侧都归一成 LF：

- `make_patch._entry_bytes()` 写进 zip 前把 CRLF 换成 LF（二进制按 `\x00` 探测后原样）；
- `updater.sha256_normalized()` 比对本地文件时先归一。

zip 自身的 sha256 校验仍按**原始字节**算（`sha256_file`），两者不要混用。

### 用户侧

```powershell
# 查
python -m harness.updater --check
# 装（先下 zip，再带 manifest 应用；应用后重启程序）
python -m harness.updater --apply patch-1.5.11.zip --manifest latest.json
# 回滚
python -m harness.updater --rollback data\update-backup\<时间戳>
```

### 安全边界（写死在代码里）

- 只覆盖白名单：`harness/ plugins/ webui/ evals/ skills/ protocols/` + 根目录 `.py`
- 拒：`data/ logs/ memes/ image_cache/ ...`、`bot_config.json`、`.env`、`tests/`
- 拒：`../`、绝对路径、盘符
- sha256 不匹配 → 不写盘
- 覆盖前逐文件备份到 `data/update-backup/<时间戳>/`
