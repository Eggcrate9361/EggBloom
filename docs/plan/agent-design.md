# EggBloom Agent 设计方案

> 目标：给主程序加一个**真正好用**的 agent 能力，**不是插件**，而是主程序基础设施的一部分。
> 记忆走本体（super_memory + sandglass），harness 能力（session_log / retention / spill / 策略快照）全部真正用上。
> 交互要有使用上的**独特便利**，且贴合 EggBloom 自身语境。

---

## 1. 两个入口，一套内核

| 入口 | 场景 | 触发方式 |
|---|---|---|
| **主程序 Agent 对话页** | 桌面端，用户直接对话、委派多步任务 | 侧栏导航新增一项，点击进入 |
| **QQ 群内 Agent 模式** | 群里委派需要真实执行的任务 | **意图识别 + 权限门槛**双闸（非死板指令） |

两者共用同一个内核 `harness/agent_loop.py`，区别只在输入输出适配层。

## 3. 后端形态（用户已定：折中）

- **逻辑全在 `harness/agent_loop.py`**（新增），不塞进 bot_core。
- bot_core 只加**薄路由**：
  - `POST /api/agent/chat`（SSE 流式）→ 委派 agent_loop
  - `POST /api/agent/abort` → 中止当前会话
  - `GET  /api/agent/history` → 读 session_log 派生历史
- webui_server 已有 `BOT_CORE_URL` 转发机制，前端请求经它转发，**不新增端口**。

---

## 4. 群内触发：为什么"不能随便用"

用户明确："群聊里有特定的使用功能肯定不能随便用。" → 设计成**双闸**：

**闸一 · 权限**：仅 `command_admins` / `target_qqs`（复用既有 `_is_authorized`）。
非白名单者即使说了"帮我干活"也不会进 agent 模式，走普通闲聊。

**闸二 · 意图**：必须是**明确的执行意图**，不是随便一句话。识别信号：
- 触发词 + 执行动词组合（如「小a 去帮我……」「@小a 干活：……」）
- 排除闲聊（"你在干嘛"不是）
- 支持显式强触发词作为兜底

**为什么不做成 `!agent` 前缀**：用户觉得"指令太没意思"。
→ 做成**自然语言意图 + 权限**，既安全又不机械，且贴合 bot 叫「小a」的语境。

## 5. 独特点：真正提升使用效率 + 贴合 EggBloom

不做花哨面板，做**用得上的**：

### (1) 执行轨迹卡（EggBloom 式）
每步工具调用在对话流里显示为一张卡：工具名 + 参数摘要 + 结果摘要 + 耗时。
- 可**折叠/展开**看完整结果（超长自动走 spill，卡里给路径）
- 可**单步重跑**
- 暗金配色，与现有 UI 一致

### (2) 沙漏时间轴（贴合 sandglass）
对话页侧边一条细时间轴，显示：
- 距上次对话多久（呼应 sandglass 的"时间流逝"意象）
- 本次会话已执行多少步、花了多少 token
- 不是装饰，是**任务进度 + 成本可视**

### (3) 会话即日志（可回放）
因为底层是 session_log，**任何一次 agent 会话都能完整回放**：
- 刷新页面不丢（从日志重建）
- 可以"从某一步重来"
- 这是真的能力，不是 UI 效果

### (4) 键盘优先
- `Enter` 发送 / `Shift+Enter` 换行
- `Esc` 中止当前执行
- `↑` 调出上条输入

## 7. harness 高标准落点（关键：不是摆设）

| harness 件 | 在 agent 里的实际用途 |
|---|---|
| `session_log` | agent 会话的事件溯源：每次用户输入/工具调用/模型输出都 append；历史从日志派生；可回放 |
| `retention` | 工具返回超长时的有界保留（中文字节安全） |
| `spill` | 工具返回超预算时落盘，卡里给路径 + read 提示，模型可再读 |
| 策略快照追加 | agent 的模式切换（如"只读模式"/"允许危险工具"）用追加快照，不改写前缀 |

---

## 8. 实施顺序

1. `harness/agent_loop.py` —— 内核（对话循环 + 工具分发 + session_log 集成 + retention/spill）
2. bot_core 薄路由 + 群内意图/权限闸
3. 测试（内核单测 + 群内触发单测 + 回放一致性）
4. 前端 Agent 页（导航项 + 执行轨迹卡 + 沙漏时间轴 + 键盘）
5. 同步运行副本 + 端到端验证

---

## 9. 红线

- 不用 `!agent` 死板前缀
- 不新增独立进程/端口（复用 webui_server 转发）
- 不重写工具，只复用
- 群内 agent **默认关**，且必须双闸通过
- 每项独立 commit
