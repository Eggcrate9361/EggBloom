## 2. P0 通路：五刀，每刀可单独回退

原则：**每刀一个提交、一个开关、一个验收**；开关默认关，灰度通过再开。

### 刀 1：`life_context.compose()`（纯新增，不接主链）

- 新增 `harness/life_context.py`：把现在散在 `_build_static_prompt` /
  `dynamic_parts` / 插件注入里的东西收成一个函数：
  `compose(sender, group_id, scene, budget) -> {static, dynamic, meta}`
- 主链**先不调用**，只加一个 `test_life_context.py` 证明"同样的输入产出同样的串"
  （对着现有逻辑取基准，逐段比对）。
- 验收：新用例 100% 通过；生产行为零变化（diff 只加文件）。

### 刀 2：主链接到 `compose`（开关 `life_context_enable`，默认关）

- `_call_deepseek_sync` 的 dynamic 段改为：开关开 → `compose()`；关 → 原逻辑。
- 灰度：本机开 → 观察 24h（日志对比：prompt 长度、命中率、报错）。
- 验收：开关关闭时逐字节等于旧输出（golden 测试）；打开时不崩、长度差 <2%。
- 回退：关开关即可，不动代码。

### 刀 3：`deep_task` 工具（agent 从"模式"变"工具"）

- `harness/agent_service.run_chat` 包成工具 `deep_task(task, context)`；
  走 `tool_registry` 的 `GROUP_DEEP`，只在"可干活"打开时注入。
- 入口不再直接调 `agent_service`；私聊/群聊都走主链，模型自己决定是否调工具。
- 开关：`agent_as_tool`（默认关）→ 灰度后默认开。
- 验收：
  1. `grep -n "agent_service.run_chat" bot_core.py` 只剩工具包装处；
  2. 同一 trace id 同时出现在"普通回复"与"工具调用"两类日志里（`session_log` 已带 trace）。
- 回退：关 `agent_as_tool`，入口退回旧分支（旧代码保留一个版本）。

### 刀 4：两个开关合并为「可干活」

- `agent_private_enable` + `agent_group_enable` → `agent_can_work`（新键）。
- 迁移：读配置时旧键仍认（任一为 True 即 True），**写回只写新键**。
- 验收：旧配置启动后行为不变；配置页只出现一个开关；`test_config_parity` 绿。

### 刀 5：出口统一（P1 的一半，先做 QQ）

- `harness/outbound.py`：文本/图片/表情/poke 一个队列，串行 + 限频 + 去重 + 重试 + 日志。
- `smart_send*` 退化成薄封装（函数体 3 行以内）。
- 验收：`grep "send_group_msg\|send_private_msg" plugins/ protocols/ bot_core.py`
  只剩 outbound；重试计数在日志里可见。
- 回退：`outbound_enable` 关 → 直连旧路径。

## 3. P1.5 AIGC：三刀

1. **任务层**：`harness/aigc_task.py` + `/api/aigc/*`，先把现有 ComfyUI 迁进来
   （页面不变，只换后端）。验收：生成一张图，`data/media/image/<date>/` 有产物 + 元数据。
2. **语音**：piper TTS（离线）+ 试听；依赖进 `data/aigc/venv/`。
   验收：合成 3 秒语音，时长 1~10s、>1KB。
3. **闭环**：faster-whisper 转写上一步的音频，编辑距离 ≤1；页签点亮。

视频只留接口（`aigc_video_backend` 默认空）。

## 4. 每刀的节奏

```
① 先写用例（红）→ ② 改代码（绿）→ ③ 部署运行副本 → ④ 真机看一眼
→ ⑤ 提交（<type>(<scope>): MM-DD 说明）→ ⑥ 推 origin/main
```

- 一天最多两刀；每刀结束必须 `run_all_tests.py` 绿。
- 涉及人格式的提交前跑 `python run_all_tests.py --evals`（40+13）。
- 部署只同步改动文件 + 测试文件，**永不同步 `bot_config.json` / `data/`**。

## 7. 风险与红线

| 风险 | 处理 |
|---|---|
| 主链 prompt 变化导致人格漂移 | 刀 2 用 golden 逐字节比对 + `--evals` |
| 工具化后模型乱调 `deep_task` | 工具描述写清"只在需要多步干活时"；关开关即回退 |
| 出口统一引入延迟 | 队列异步、首字不受影响；观测 `gen_send` 时序 |
| AIGC 依赖污染解释器 | 独立 venv（`data/aigc/venv`），本体 `pip list` 必须不变 |

**不做**：不重构 `bot_core.py` 的大结构；不动人格与记忆代码；不在 1.6.0 碰分离。
