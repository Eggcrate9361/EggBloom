EGO 使用引导
第一次使用 EGO？花 1 分钟完成基础配置，之后可随时返回本页调整。
第 1 步：你是谁
告诉 bot 身份和性格，这是人格模块的核心。
第 2 步：连接 QQ（协议层）
机器人要能说话，先得通过协议层（NapCat）连上你的 QQ。通常 1 分钟搞定：
① 进 「协议」 面板，点 「自动探测」 自动找到 QQ.exe 与 NapCat
② 没找到就点 「浏览」 手动选择路径 → 「保存」
③ 点 「启动协议层」，QQ 弹出登录就 扫码
④ 状态「已就绪」后点 「启动 Bot」
⚠ NapCat 版本必须匹配你的 QQ 版本（GitHub NapCatQQ Releases 下载对应包）
第 3 步：记忆
EGO 会把重要对话沉淀为记忆，在之后聊天中主动召回。向量化让记忆检索更准。
提示：记忆库与向量服务状态可在本页「启动状态与问题」中查看。
第 4 步：说话风格
bot 会学习群里的说话风格。先选一种基础风格，之后自动进化。
风格学习需要 bot 在群聊中积累样本才会生效，无需手动配置。
第 5 步：黑话学习
黑话让 bot 更像圈内人。可以现在开始学习，也可以之后在页面里随时发起。
可选，会调用 AI 联网学习候选
第 6 步：免费 API Key（推荐）
群聊决策的「看图」和网页操作的「看图判断」需要一个 AI 视觉 Key。智谱 GLM 的 glm-4-flash（文本）和 glm-4v-flash（看图）完全免费、不限量，注册 30 秒搞定。也可以跳过，之后在「插件」页随时补。
注册步骤：手机号登录 → 实名认证 → 「API Keys」→ 新建 → 复制。填了之后「群聊决策」与「网页操作」的看图能力自动可用。
第 7 步：插件速览
以下插件默认已启用，全部可在侧栏「插件」页随时微调：
群聊决策 （判断该不该说话 / 看图 / 主动参与）
模型用第 5 步的智谱 Key，看图自动启用。
联网搜索 （提到"最新 / 股价 / 天气"等自动联网查证）
用主模型 Key（设置页已配），无需额外配置。
网页操作 （真实打开网页 / 截图 / 点按钮）
看图助手可复用第 5 步智谱 Key；浏览器引擎 Playwright 需 pip install playwright + playwright install chromium。
记忆 / 风格 / 黑话 （前几步已配好）
记忆向量检索由 LiGGUF 本地引擎驱动，无需外网。
第 8 步：确认并完成
将保存你的配置。之后可随时在「子模块开关」中调整。
