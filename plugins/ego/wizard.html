EGO 首次配置
只需几步，完成人格、模型提供商与协议层初始化。
第 1 步：人格基础
先让 bot 知道自己是谁，以及怎么说话。
第 2 步：模型提供商
选择默认的模型提供商。之后可在设置里随时更改。
OpenAI
GPT 系列，需 API Key。
Anthropic
Claude 系列，需 API Key。
Google
Gemini 系列，需 API Key。
Nous / Hermes
Hermes 自有路由。
Custom / 本地
OpenAI 兼容端点，或本地 Ollama。
第 3 步：协议层与平台
选择你想先接通的对话入口。
飞书 Feishu
通过飞书机器人收发消息。
微信 WeChat
通过微信个人号/公众号。
Telegram
通过 Telegram Bot。
Discord
通过 Discord Bot。
仅本地 WebUI
先不接外部平台，只用本地页面。
第 4 步：确认并应用
检查你的配置，点击保存后将写入 EGO 配置。
