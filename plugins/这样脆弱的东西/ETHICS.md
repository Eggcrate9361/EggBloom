# 人格蒸馏伦理协议 Ethics Protocol

> **适用对象**：这样脆弱的东西 插件的所有使用者
> **版本**：v1.0
> **标准**：Persona-File v1.0

---

## 第一章 总则

### 1.1 原则

人格蒸馏技术具有高度敏感性。本协议确立以下不可违背的原则：

1. **自主权**：被蒸馏对象的人格数据主权归其本人所有
2. **最小必要**：只收集蒸馏所需的最少数据
3. **可撤回**：任何时刻可撤回授权并删除全部数据
4. **不可滥用**：蒸馏结果不得用于歧视、操控或伤害

### 1.2 适用范围

本协议适用于通过 这样脆弱的东西 插件进行的任何人格蒸馏操作，包括：
- 从聊天记录提取人格模型
- 从文本数据提取人格模型
- 蒸馏结果的存储、使用、传播

### 1.3 责任主体

- **蒸馏执行者**：插件使用者，承担数据收集和使用的全部责任
- **被蒸馏者**：人格数据的原始来源，享有知情权和删除权
- **平台**：EggBloom Desktop，不承担蒸馏行为的法律责任

---

## 第二章 知情同意

### 2.1 基本规则

**原则上，蒸馏前必须获得被蒸馏者的明确知情同意。**

例外情况（仅限以下场景，且必须在事后通知被蒸馏者）：
- 蒸馏对象为蒸馏执行者本人
- 蒸馏对象为公开数据（公开发布的内容）
- 蒸馏对象已明确授权第三方蒸馏

### 2.2 知情同意内容

知情同意必须包含：
- 蒸馏目的说明
- 数据范围说明（哪些数据会被收集）
- 数据用途说明（蒸馏结果将如何使用）
- 存储位置说明
- 删除方式说明
- 撤回授权的方式

### 2.3 同意的形式

同意可以是：
- 书面同意（聊天记录、邮件、签名文件）
- 口头同意（需有第三方见证或录音）
- 行为默示（如对方主动提供大量个人数据）

**明确拒绝的情况**：
- 对方明确表示反对蒸馏
- 对方要求删除已有蒸馏结果
- 对方处于非自愿状态（胁迫、欺骗）

### 2.4 未成年人特殊规则

**蒸馏 14 岁以下未成年人的人格数据，必须同时获得其监护人同意。**

蒸馏 14-18 岁未成年人的人格数据，建议获得监护人同意，但非强制。

## 第三章 数据范围

### 3.1 允许的数据源

以下数据来源允许用于人格蒸馏：
- 被蒸馏者本人提供的数据
- 被蒸馏者公开发布的内容
- 蒸馏执行者与被蒸馏者之间的对话记录
- 被蒸馏者授权第三方提供的内容
- 公开可获取的文本数据

### 3.2 禁止的数据源

以下数据来源禁止用于人格蒸馏：
- 通过黑客手段获取的数据
- 通过欺骗手段获取的数据
- 通过胁迫手段获取的数据
- 被蒸馏者明确声明为私密的数据
- 涉及他人隐私的数据（除非已获该第三方同意）

### 3.3 敏感信息处理

蒸馏过程中如发现以下敏感信息，必须采取额外保护措施：

| 类别 | 示例 | 处理方式 |
|------|------|---------|
| 身份信息 | 身份证号、银行卡号 | 立即从蒸馏数据中脱敏 |
| 健康信息 | 疾病、心理状况 | 仅保留与人格相关的部分 |
| 财务信息 | 收入、债务 | 仅保留消费模式特征 |
| 政治立场 | 政治观点 | 不纳入人格模型 |
| 性取向 | 性取向、性偏好 | 不纳入人格模型 |
| 宗教信息 | 宗教信仰 | 不纳入人格模型 |
| 位置信息 | 精确位置 | 仅保留大致区域 |
| 生物特征 | 面部、声纹 | 禁止用于蒸馏 |

## 第四章 数据存储

### 4.1 存储原则

- **本地优先**：蒸馏数据优先存储在用户本地设备
- **加密存储**：敏感数据必须加密存储
- **最小化**：只存储蒸馏所需的数据，不保留原始数据副本
- **隔离存储**：不同被蒸馏者的数据必须隔离存储

### 4.2 存储位置

人格文件存储路径：
```
plugins/这样脆弱的东西/data/distills/{user_id}_L{n}.md
```

禁止将人格文件存储在：
- 公开可访问的服务器
- 未加密的云存储
- 共享文件系统
- 版本控制系统（如 Git）

### 4.3 数据保留

- 蒸馏执行者应定期审查已有人格文件
- 超过 12 个月未使用的人格文件应标记为"待审查"
- 超过 24 个月未使用的人格文件应删除

---

## 第五章 数据删除

### 5.1 删除权利

被蒸馏者（或其监护人/法定代理人）有权在任何时间要求删除其人格数据。

### 5.2 删除流程

收到删除请求后，蒸馏执行者必须在 30 天内完成：

1. **立即响应**：确认收到删除请求，告知预计完成时间
2. **停止使用**：立即停止使用该人格文件进行任何操作
3. **删除数据**：从所有存储位置彻底删除人格文件
4. **验证删除**：确认数据已无法恢复
5. **书面确认**：向请求方提供删除完成的书面确认

### 5.3 删除范围

删除请求覆盖：
- 人格文件本身（.md 文件）
- 溯源项链中的所有引用数据
- 蒸馏审计日志中的相关记录
- 任何从人格文件衍生的数据

### 5.4 备份数据

已删除的数据如果存在于备份中：
- 本地备份：必须在 30 天内删除
- 云备份：必须在下一个备份周期后删除
- 无法删除的备份：必须标记为"已撤销"并禁止访问

## 第六章 使用限制

### 6.1 允许的使用

以下用途允许使用人格蒸馏结果：
- 模拟对话（用于测试、研究、娱乐）
- 个性化交互（在获得同意的前提下）
- 学术研究（需匿名化处理）
- 心理咨询辅助（需专业监督）

### 6.2 禁止的使用

以下用途禁止使用人格蒸馏结果：
- 冒充被蒸馏者进行欺诈
- 操控被蒸馏者的决策
- 对第三方造成误导
- 商业牟利（未经被蒸馏者授权）
- 歧视性决策（招聘、贷款、保险等）
- 武器化使用（军事、情报等）
- 制作深度伪造内容（Deepfake）

### 6.3 责任限制

蒸馏执行者不得将人格蒸馏结果用于以下场景：
- 替代被蒸馏者的法律决定
- 替代被蒸馏者的医疗决定
- 替代被蒸馏者的财务决定
- 替代被蒸馏者的安全决策

## 第七章 审计与追踪

### 7.1 审计日志

每次蒸馏操作必须记录：

| 字段 | 说明 |
|------|------|
| timestamp | 蒸馏时间 |
| operator | 蒸馏执行者 |
| subject | 被蒸馏者标识 |
| data_sources | 使用的数据源列表 |
| data_volume | 数据量（条数） |
| distill_level | 蒸馏等级（L0-L4） |
| token_usage | Token 用量 |
| consent_status | 同意状态 |
| purpose | 蒸馏目的 |
| outcome | 蒸馏结果 |

### 7.2 审计日志存储

审计日志存储位置：
```
plugins/这样脆弱的东西/data/audit/
```

审计日志保留期限：至少 2 年。

### 7.3 审计日志格式

```json
{
  "timestamp": "2026-08-15T16:40:00Z",
  "operator": "user@example.com",
  "subject": "10000002",
  "data_sources": ["chat_logs", "super_memory"],
  "data_volume": 1500,
  "distill_level": "L1",
  "token_usage": 500000,
  "consent_status": "written",
  "purpose": "personal_simulation",
  "outcome": "success",
  "ethics_version": "v1.0"
}
```

## 第八章 违规处理

### 8.1 违规类型

| 违规类型 | 严重程度 | 处理方式 |
|---------|---------|---------|
| 未获同意蒸馏 | 严重 | 立即删除，通知被蒸馏者 |
| 数据泄露 | 严重 | 立即通知受影响方，公开报告 |
| 禁止用途使用 | 严重 | 立即停止，上报相关机构 |
| 拒绝删除 | 严重 | 法律追责 |
| 审计日志缺失 | 中等 | 补录，加强监控 |
| 敏感信息未脱敏 | 中等 | 立即脱敏，加强审查 |

### 8.2 违规报告

发现违规行为后，蒸馏执行者必须：
1. 立即停止违规操作
2. 在 48 小时内评估影响范围
3. 在 72 小时内通知受影响方
4. 在 7 天内提交整改报告

## 第九章 特殊场景

### 9.1 已故人士

蒸馏已故人士的人格数据：
- 必须获得其法律继承人的书面同意
- 不得用于商业目的（除非继承人已授权）
- 不得用于制作具有误导性的内容

### 9.2 公众人物

蒸馏公众人物的人格数据：
- 仅可使用其公开发布的内容
- 不得使用私人数据
- 蒸馏结果不得用于冒充

### 9.3 组织/团体

蒸馏组织或团体的人格数据：
- 必须获得组织授权
- 仅可使用组织公开数据
- 不得用于替代组织决策

### 9.4 跨司法管辖区

当蒸馏执行者与被蒸馏者处于不同司法管辖区：
- 必须遵守双方所在地的法律
- 如法律冲突，取更严格的保护标准
- 不得利用法律差异规避义务

## 第十章 协议管理

### 10.1 协议版本

| 版本 | 日期 | 变更摘要 |
|------|------|---------|
| v1.0 | 2026-08-15 | 初始版本 |

### 10.2 协议更新

协议更新后：
- 所有已有人格文件的蒸馏审计日志中的 `ethics_version` 字段将标记为旧版本
- 用户应在 90 天内审查其蒸馏操作是否符合新版本
- 严重违规（如未获同意）不受版本变更影响

### 10.3 协议豁免

以下情况可申请协议豁免：
- 学术研究（需学术机构批准）
- 法律调查（需法律授权）
- 公共安全（需官方授权）

豁免申请必须：
- 书面提交，说明豁免原因和范围
- 明确数据使用限制和删除时间
- 接受事后审计
